# SCT_ML_3

# 🐶🐱 Cats vs Dogs Classification using SVM

This project is part of my Machine Learning Internship at SkillCraft Technology.

The model classifies images as either Cats or Dogs using:
- OpenCV
- NumPy
- Scikit-learn
- Support Vector Machine (SVM)

---

## 📌 Project Overview

The project uses image preprocessing and an SVM classifier to perform binary image classification.

### Workflow
1. Load dataset images
2. Resize images
3. Flatten image arrays
4. Train SVM classifier
5. Predict Cat or Dog images
6. Visualize predictions

---

Dogs vs Cats Dataset from Kaggle
